# Akash Mondal — Portfolio

A responsive, dependency-free cybersecurity portfolio built for GitHub Pages.

## Local preview

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## GitHub Pages

The included workflow deploys the repository root to GitHub Pages. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

## Content

- `index.html` — portfolio content and semantic structure
- `styles.css` — responsive visual system and motion states
- `script.js` — 3D canvas network, ambient motion, and interaction
- The public build intentionally excludes the source résumé and phone numbers.
